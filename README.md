# קלסר תעבורה

קלסר עזר דיגיטלי לתובע תעבורה: הליכים, מתחמי ענישה ופסיקה מקושרת. מפורסם כאתר סטטי דרך GitHub Pages וניתן להתקנה כאפליקציה על מסך הבית בטלפון (PWA).

## התקנה על הטלפון

**אייפון (Safari):** פתחו את הקישור ← כפתור השיתוף ← "הוסף למסך הבית".
**אנדרואיד (Chrome):** פתחו את הקישור ← תפריט שלוש הנקודות ← "התקן אפליקציה" / "הוסף למסך הבית".

## עדכון קישורי פסיקה (בעצמך, בלי לגעת בקוד)

הקובץ [`links.json`](./links.json) הוא מיפוי פשוט של **שם התיק ← קישור לפסק הדין**. כל תיק שמופיע בקלסר עם כותרת מודגשת (⚖) מקבל שורה בקובץ הזה. אפשר לערוך אותו ישירות באתר GitHub, גם מהטלפון:

1. נכנסים ל־`links.json` במאגר.
2. לוחצים על סמל העיפרון (Edit).
3. משנים את הכתובת שליד שם התיק המבוקש (או משאירים ריק אם אין קישור).
4. גוללים למטה ולוחצים "Commit changes".

תוך דקה השינוי מופיע באתר — אין צורך לגעת ב־`index.html` או בשום קובץ אחר. שם התיק בקובץ חייב להיות זהה בדיוק לכותרת שמופיעה בקלסר (כולל מספר התיק).

## עדכון התוכן

הקובץ `index.html` נוצר מ־`gen_html.py` + `page_template.html` (בתיקיית העבודה שיצרה את הקלסר). לעדכון: לערוך את מקור התוכן, להריץ שוב את סקריפט הבנייה, להעתיק את `index.html` החדש לכאן, ולדחוף (`git push`).
